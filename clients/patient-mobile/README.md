# Clinova Patient Mobile Application

React Native + Expo + TypeScript mobile application for Clinova patients.

## Planned Stack (Step 11)
- **Framework**: React Native, Expo SDK, TypeScript
- **State Management**: TanStack Query (`@tanstack/react-query`)
- **Navigation**: `@react-navigation/native`, `@react-navigation/native-stack`
- **Security**: `expo-secure-store` for hardware-backed token storage
