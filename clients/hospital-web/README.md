# Clinova Hospital Web Dashboard

React + TypeScript + Vite web dashboard for Clinova hospital administration.

## Planned Stack (Step 10)
- **Framework**: React 18/19, Vite, TypeScript
- **State Management**: TanStack Query (`@tanstack/react-query`)
- **Routing**: `react-router-dom`
- **Styling**: Vanilla CSS Design Tokens (Clinical Teal/Navy/Slate)
