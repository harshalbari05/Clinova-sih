# Clinova Patient Web Portal

React + TypeScript + Vite web application for Clinova patients.

## Planned Stack (Step 9)
- **Framework**: React 18/19, Vite, TypeScript
- **State Management**: TanStack Query (`@tanstack/react-query`)
- **Routing**: `react-router-dom`
- **Styling**: Vanilla CSS Design Tokens (Calm Medical Blue/Slate)
