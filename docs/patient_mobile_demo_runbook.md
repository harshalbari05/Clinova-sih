# Clinova Patient Mobile — Live Demo & Operator Runbook

**Audience:** SIH Evaluators, Clinova Engineers, Demo Operators  
**Component:** Clinova Patient Mobile (`Clinova-sih/clients/patient-mobile`)  
**Backend:** Clinova FastAPI Server (`Clinova-sih/backend`)  

---

## 1. Prerequisites & Environment Setup

### Required Tools
- Node.js `^22.13.0` or `>=20.19.4` (LTS v22.14.0 recommended)
- Python 3.11+
- Expo CLI / Expo Go on mobile or Android Studio Emulator
- PowerShell / Command Prompt

---

## 2. Starting the Backend Server

From the root of the repository:

```powershell
cd Clinova-sih\backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

*Note: Binding to `0.0.0.0` allows connections from both the Android emulator (`10.0.2.2`) and physical phones on your local Wi-Fi network.*

---

## 3. Starting the Expo Mobile Client

From the mobile directory:

```powershell
cd Clinova-sih\clients\patient-mobile
npx expo start
```

### Running on Android Emulator
- Press `a` in the terminal to launch on the running Android emulator.
- The app will automatically connect to `http://10.0.2.2:8000/api/v1`.

### Running on a Physical Android Phone
1. Connect phone and development laptop to the **same Wi-Fi network**.
2. Find your computer's local IP address:
   ```powershell
   ipconfig
   # Look for IPv4 Address e.g. 192.168.1.100
   ```
3. Open the **Expo Go** app on your phone and scan the QR code displayed in your terminal.
4. If connecting to backend over LAN:
   - Go to **Profile** screen tab in the mobile app.
   - Tap **Configure** under "Network & Backend Server".
   - Enter `http://<your-laptop-ip>:8000/api/v1` (e.g. `http://192.168.1.100:8000/api/v1`) and tap **Save**.

## 6. Troubleshooting & Diagnostics

| Issue | Cause | Resolution |
|---|---|---|
| Network Error / Axios Timeout | Phone cannot reach laptop IP | Ensure phone and laptop are on the same Wi-Fi network and laptop firewall allows inbound traffic on port 8000. |
| Microphone permission denied | Permission dismissed on device | Open Android Settings → Apps → Expo Go → Permissions → Microphone → Allow while using app. |
| Camera preview black | Camera permission required | Open Android Settings → Apps → Expo Go → Permissions → Camera → Allow. |
| 401 Unauthorized | Token expired or invalid | Go to Profile → Sign Out and log back in to refresh JWT. |
